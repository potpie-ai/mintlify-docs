## Connecting Sentry

1. Go to <a href="https://app.potpie.ai/sign-in" className="mode-link">Potpie</a> → **Integrations**
2. Click **Connect Sentry**
3. Complete the OAuth consent screen on Sentry's side
4. Potpie stores your access and refresh tokens encrypted in PostgreSQL, linked to your Sentry organization

<Note>The same Sentry organization cannot be connected more than once per user. Attempting to reconnect the same organization returns a duplicate error.</Note>


## What It Provides

Unlike other integrations, Sentry does not expose agent-callable tools. Instead, connecting Sentry makes your organization's data accessible to the service layer — projects, issues, and events can be retrieved and used as context in conversations.


## Token Refresh

Potpie automatically refreshes the Sentry access token when it expires. No action is required from the user.


## Webhooks

Sentry can send an issue and project events to Potpie in real time. Webhook registration is done manually on Sentry's side — Potpie does not register webhooks automatically at connection time.
