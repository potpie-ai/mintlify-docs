title: "Confluence Integration"
---

Connect Confluence to Potpie to give agents the ability to read, search, and update pages directly from your codebase conversations.

## Connecting Confluence

1. Go to <a href="https://app.potpie.ai/sign-in" className="mode-link">Potpie</a> → **Integrations**
2. Click **Connect Confluence**
3. Complete the OAuth consent screen on Atlassian's side
4. Potpie stores your access and refresh tokens encrypted in PostgreSQL, linked to your Confluence Cloud site

<Note>Once connected, agents can use the following Confluence tools whenever they are included to the agent's tool list.</Note>

## What Agents Can Do

Once connected, agents can use the following Confluence tools when they are included in the agent's tool list.

| Tool | What it does |
|---|---|
| `get_confluence_spaces` | Lists all accessible spaces |
| `get_confluence_space_pages` | Lists pages within a space |
| `get_confluence_page` | Reads full page content and version number |
| `search_confluence_pages` | CQL-based full-text search across spaces |
| `create_confluence_page` | Creates a new page in a space |
| `update_confluence_page` | Updates a page's title or body |
| `add_confluence_comment` | Posts a footer comment or threaded reply |

All tools require an active Confluence integration. If none is found, the tool returns an error prompting the user to connect Confluence first.

<Note>`update_confluence_page` always requires calling `get_confluence_page` first to obtain the current version number. Confluence rejects updates that do not include the correct incremented version.</Note>


## Token Refresh

Potpie automatically refreshes the Confluence access token before it expires. No action is required from the user.
