## Connecting Jira

1. Go to <a href="https://app.potpie.ai/sign-in" className="mode-link">Potpie</a> → **Integrations**
2. Click **Connect Jira**
3. Complete the OAuth consent screen on Atlassian's side
4. Potpie stores your access and refresh tokens encrypted in PostgreSQL, linked to your Jira Cloud organization

<Note>Once connected, agents can use the following Jira tools whenever they are included to the agent's tool list.</Note>

---

## What Agents Can Do

Once connected, agents can use the following Jira tools when they are included in the agent's tool list.

| Tool | What it does |
|---|---|
| `get_jira_issue_tool` | Fetches a single issue by key like summary, status, assignee, priority, labels, and description |
| `search_jira_issues_tool` | Searches issues using JQL with pagination support |
| `create_jira_issue_tool` | Creates an issue with summary, description, type, priority, assignee, and labels |
| `update_jira_issue_tool` | Updates fields on an existing issue |
| `add_jira_comment_tool` | Posts a comment to an issue |
| `transition_jira_issue_tool` | Moves an issue through its workflow by transition name |
| `get_jira_projects_tool` | Lists all accessible projects |
| `get_jira_project_details_tool` | Returns valid issue types, priorities, and statuses for a project |
| `get_jira_project_users_tool` | Lists assignable users for a project |
| `link_jira_issues_tool` | Links two issues like Blocks, Relates, and other link types |

All tools require an active Jira integration. If none is found, the tool returns an error prompting the user to connect Jira first.

## Token Refresh

Potpie automatically refreshes the Jira access token before it expires. No action is required from the user.

## Webhooks

Potpie registers a webhook on your Jira Cloud site at connection time, subscribing to issue created, updated, deleted, and comment events. Webhook events are verified using a signed JWT before processing.
