Potpie allows you to perform **Spec Driven Development**, on large messy codebases. Our proprietary <a href="/concepts/knowledge-graph" className="mode-link">knowledge graph</a> allows our agents to understand the users context in much great detail required to perform complex **multi-hop reasoning** required for debugging, refactoring, etc

## Connect your repository
Index a branch and generate a project context to initialize Potpie’s graph, enabling agents to reason over real call paths and architectural boundaries from your first spec.

If you want to go deeper, create a custom agent with its own role and tools.

<a href="https://app.potpie.ai/sign-in" className="mode-link"> Connect repository → </a>
