**Ask** is Potpie's Q&A interface. It answers questions about your codebase by navigating the <a href="/concepts/knowledge-graph" className="mode-link">knowledge graph</a>  to find exactly what you need to know.

When a question involves a third-party library, it retrieves external documentation via web-Fetch.Follow-up questions in the same session retain full context from what came before.

To start using Ask, see the <a href="/tutorials/explore-your-codebase" className="mode-link">Explore Your Codebase tutorial</a>.


## How It Navigates

Before generating a response, Ask first classifies the question to determine whether it concerns behavior, implementation, location, or design intent.
Complex questions are broken into components and addressed one by one.

## How It Responds

Answers are structured with headers, code snippets, and citations to exact file locations. File paths are shown relative to the repository root. Every requirement the question raised is verified before the response is returned.


## Using the API

The <a href="/api-reference/endpoint/create-conversation-and-message" className="mode-link">Create Conversation and Message</a> endpoint opens a session against a <a href="/concepts/parsing" className="mode-link">parsed</a> project and returns a cited, markdown formatted answer in a single call.
