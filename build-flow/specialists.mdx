title: 'Specialists'
---

**Specialists** are Potpie's purpose-built agents for specific engineering tasks. Each agent is scoped for a single function and built with **structured prompting**, tool integrations, predefined skills, controlled memory, and **evaluation loops**. Agents produce testable, measurable, and reproducible behaviour across runs.

## Available specialists

| Agent | What it does |
|---|---|
| Q&A Agent | Retrieves and grounds answers in verified source material across large repositories |
| Debugging Agent | Traverses service relationships, analyzes diffs, validates contracts, and reproduces failures in sandboxed environments |
| Code Agent | Generates implementation ready code changes with full awareness of repository structure, patterns, and dependencies |

## Model compatibility

Output consistency holds across model variants as Specialists run consistently across all **foundation model** variants. As models improve, agents inherit those improvements and workflows stay unchanged. The orchestration layer standardizes response structure, execution patterns, and task level evaluation criteria.

## Composability

Specialists can be orchestrated together while preserving precision and traceability. They integrate with existing tooling, respect access controls, and produce outputs that hold up in demanding engineering workflows.
